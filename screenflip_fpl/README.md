# Screen Flip for SIGMA fp L 3.02

Open **SYSTEM → Mode Settings → Custom → More options → TOOLS → Screen Flip**.

| Mode | Picture | Status overlay |
|---|---|---|
| Off | Stock | Stock |
| 180° | Rotated 180° | Rotated 180° |
| Mirror | Left ↔ right | Stock |
| 180° + Mirror | Top ↔ bottom | Rotated 180° |

The mod stores the eight STILL/CINE selections in `\FPFLIP.CFG` on the SD card. Writes wait for edits to settle, are deferred during recording and are verified by reopening the file. Missing, short or invalid records use the build defaults (Off). Remove the file with the camera off to reset preferences. Updating the card software does not require changing the file.

See the [build instructions](../README.md#build-and-test) and [verification record](../research/README.md).
